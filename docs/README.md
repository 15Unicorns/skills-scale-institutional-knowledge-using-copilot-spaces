# OctoAcme Project Management Processes

## Overview
OctoAcme follows a structured, customer-first approach that spans the full project lifecycle — from lightweight initiation through planning, iterative execution, release, and retrospective. The process emphasizes clear ownership (named Project Manager and Product Manager), iterative delivery of small, testable increments, and data-informed decision making so teams can measure impact and iterate. Psychological safety and open feedback are also core principles to encourage learning and continuous improvement.

Work is organized on a project board with clear column states (Backlog → Ready → In Progress → In Review → QA → Done). Planning converts the project one-pager into a prioritized backlog, a Definition of Done, and a release/milestone map. Execution focuses on short, reviewable PRs that include acceptance criteria and pass CI checks; releases follow standardized checklists and rollback plans. Retrospectives capture learnings and feed prioritized action items back into the backlog to close the improvement loop.

## Key contacts (by role)
- Project Manager (PM) — coordinates delivery, schedule, and risk communication
- Product Manager (PdM) — defines outcomes, success metrics, and prioritization
- Developers — implement features, write tests, and participate in reviews
- QA / Testing — own validation, integration tests, and acceptance verification
- Stakeholders / Sponsors — provide approvals and business context
